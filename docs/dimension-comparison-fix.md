# 寸法比較の表示とRX諸元の訂正（2026-09-20）

車種ページの「普通車・ミドル・ハイルーフ」「標準・ワイド・大型」の固定目盛りを、制限値ごとの行に置き換える。数値の差、超過、上限に近い状態を文字とアイコンで示す。単一寸法の比較で入庫可を示さない。
高さは1,550 / 1,750 / 1,800 / 2,000mm、幅は1,850 / 1,900 / 1,950 / 2,050mmの例。設備の名称と上限は統一規格ではなく、実際の区画の制限を優先する旨を表示する。
上限の95%超は既存の駐車場判定と同じ注意表示。上限と同じ場合も緑のOKにしない。

## RXの対象限定訂正

レクサス・RX・5代目 (2022-)・現行型の次の5件のみ。標準装備時の数値であり、オプションによる重量増は別途確認する。

| 登録グレード | 全高（旧→新） | 重量（旧→新） |
|---|---|---|
| RX350 / 2WD | 1,700→1,705mm | 1,880→1,870kg |
| RX350 / AWD | 1,700→1,705mm | 1,950kg |
| RX350 version L / 2WD | 1,700→1,705mm | 1,950→1,870kg |
| RX350h / AWD | 1,700mm | 2,000→2,010kg |
| RX450h+ PHEV / AWD | 1,700mm | 2,110→2,160kg |

出典: [2022年11月発売時のレクサス公式カタログ・17ページ](https://cpo.lexus.jp/resource/pdf/rx_202211.pdf)、[2025年8月の公式カタログ・17ページ](https://cpo.lexus.jp/resource/pdf/rx_202508.pdf)。前者と後者でRX350およびRX450h+の対象数値が一致。RX350hは後者のAWD欄を使用。
RXの記事も全高・重量・数値による比較へ訂正する。旧世代の値、グレードID、マイカーの保存形式は変えない。全車種・全記事の再検証を完了したものではない。

## 実行手順

ソースをGitへコミットしてから、対象限定スクリプトを実行する。`db:seed`やCSV全件投入は使わない。

1. `node --env-file=.env.production --import tsx src/scripts/correct-rx-data.ts`でdry-runを保存し、上記5件と既知の旧値に一致することを確認。
2. `--apply`を付けて一括適用し、結果をGit管理外に保存。
3. 再度dry-runして変更0件を確認する。
4. Git連携で本番をデプロイし、RX車種ページ・グレードAPI・施設判定で1,705mmを確認。

スクリプトは対象の欠損・重複・未確認の値で全変更をロールバックする。テストは一時SQLiteで訂正・再実行・旧世代維持・ロールバックを検証する。
