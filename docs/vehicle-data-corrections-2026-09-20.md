# 車種監査の訂正リリース（2026-09-20）

[監査台帳](audits/2026-09-20-vehicle-data/README.md)の指摘に対する修正。監査CSVは変更前の記録として保持する。

## 適用対象

- 既存54レコードを対象に、高さ・重量の訂正／装備条件の統一34件（13車種）、乾燥重量の無効化6件、仕様不整合の非公開化6件、数値を変えない条件・名称の訂正8件。
- 新規8件：フォレスター日本仕様2025年の6グレード、フリードe:HEV CROSSTAR 5人乗りの2駆動。
- フォレスター旧登録4件、スペーシアのGSターボ1件、国内仕様を特定できないX3 G45 PHEV1件は非公開。IDを削除・再利用せず、4項目をNULLにして判定対象から外す。
- 乾燥重量6件は重量をNULLにし、車両重量が未確認であることを表示。既存の欠損時「要確認」判定を使用する。
- プリウスG/Zは19インチ、NX350はF SPORT標準20インチ、NX450h+は18インチ、フリードの対象既存行は6人乗りと明記。CR-Vの対象2件を2026年国内e:HEVとして表示する。
- ヴォクシーS-Gガソリン4WDとS-Z HVは7人乗り・標準装備に統一。重量を1,680／1,670／1,710kgとし、オプションを含む数値との混在を解消する。
- フォレスターX-BREAK S:HEVは標準1,730kg、EXは1,740kg。発売資料の列を再確認し、記事も修正した。
- クロストレック1,575mm、NX450h+ 18インチの1,990kg、ジムニー4ATの1,040kgは維持する。

一次資料・変更前後の値・対象キーは [訂正一覧](../src/db/vehicle-audit-corrections.json) と [追加一覧](../src/db/vehicle-audit-additions.json) に記録。対象キーはメーカー、車種、世代、フェーズ、グレード、駆動、変速機を使用する。

## 表示と記事

車種詳細と駐車場の判定に装備条件とメーカー資料リンクを表示。旧来の一律「現行型」表示を「登録仕様（年式・装備を確認）」に変更し、AT/MTもグレード選択に表示する。代表グレードは公開された最新世代を優先する。

車種記事13本と比較記事2本を更新。特にヴォクシー、セレナ、フリード、NX、プリウス、フィット、クロストレック、スペーシアでは対象年式・装備を明示し、単一項目から入庫可能と断定する説明を整理した。スペーシアの記事は2026年5月のメーカー諸元により2WD/4WDとも全高1,785mmと訂正する。

保存済みマイカーは同じIDで最新データを照会する。取り下げたIDを別グレードへ自動変換せず、再選択を求める。ヘッダーには保存時の古い寸法を表示しない。

## 適用方法

ユーザーから本番反映まで承認済み。変更をGitへ記録し、下記の対象限定処理を実行する。`db:seed` は実行しない。

```sh
# 認証値はgit管理外の環境ファイルから読み込む。出力に認証値は含まれない。
node --env-file=.env.production --import tsx src/scripts/correct-vehicle-audit.ts
node --env-file=.env.production --import tsx src/scripts/correct-vehicle-audit.ts --apply
node --env-file=.env.production --import tsx src/scripts/correct-vehicle-audit.ts
```

dry-runは読み取りのみ。applyはマイグレーション0002、既存54件、追加8件を同一トランザクションで反映する。未知の変更・欠損・重複・一部適用を検出した場合は全体をロールバック。成功後の再実行は0件となる。実行結果には更新前の対象レコードを含み、Git管理外に保存する。

DB適用後にmainへpushし、VercelのGit連携で本番を再生成する。確認はデプロイReady、対象API、公開ページ、対象外データ比較で行う。全件seedの初期データも同じ訂正一覧で補正する。

## 確認範囲と残作業

- 自動テスト：トランザクション、旧スキーマからの適用、失敗時のスキーマ取り消し、冪等性、対象外維持、重量未確認時の判定、全公開クエリからの除外、旧マイカーID、初期データの補正。
- 本番取得716件のローカル複製へ62件適用・再実行0件を確認。公開データは718件（全724件から非公開6件を除く）になる。
- 監査時に未照合だった546件を今回すべて確認したわけではない。確認済み車種にも未照合のグレード・項目がある。
- ミラー込み幅、未確認の年式・装備、海外公表値の国内仕様照合は継続課題。監査時にseed未収録だった92件は、この訂正一覧の対象を除き引き続き収録・出典確認が必要。
- `review-cc` スキルはこの環境で見つからないため、レビュー画面は未生成。コード差分の確認と自動テストで検証した。
