# 車種データ監査 — 2026年9月20日

RXの訂正後、ほかの車種に誤りがないかを本番データとメーカー一次資料で調査した。**数値の不一致を13車種・32件で確認した。ほかに、乾燥重量の混入、世代・グレードの不整合、装備条件の不足がある。** 本監査ではアプリ・記事・本番DBの訂正は実施していない。

## 調査範囲と読み方

- 対象コード: `81a9311`（RX訂正後）。
- 本番DB取得: 2026-09-20 15:33 JST。読み取り専用トランザクションで取得。

- **メーカー資料未照合は546レコード。203車種は資料照合に未着手。** 確認済み車種の中にも未確認グレードがある。
- 記事: 全85ファイルから車種との関連を抽出し、主要指摘の影響先を確認。85記事すべての全文ファクトチェックを終えたものではない。
- RX・アルファードの前回訂正は本番取得値に含まれるが、今回の38車種の照合件数には加算していない。

「誤り確認」は、特定した年式・仕様の公式値との不一致。参照仕様と訂正対象を確定してから反映する。「一致」は照合した項目に限り、全グレード・全年式や駐車場への入庫を保証しない。数値だけで結論を出せないものは別の区分にした。分類間には重複があり、件数を単純合計しない。

## 重量の定義が違う問題

次の値はメーカーが乾燥重量として公表した値と一致している。登録欄は一律に`weight_kg`であり、判定処理も車両重量として使用する。乾燥重量を入庫判定の車両重量として使える根拠は確認できなかった。

| 車種・グレード | 登録重量 | 一次資料 |
|---|---:|---|
| フェラーリ プロサングエ | 2,033kg | [公式発表](https://cdn.ferrari.com/cms/network/media/pdf/CS_Ferrari_Purosangue_EN.pdf) |
| ランボルギーニ レヴエルト | 1,772kg | [公式カタログ](https://www.lamborghini.com/sites/it-en/files/DAM/lamborghini/facelift_2019/model_detail/revuelto/2024/brochure/07_23/REVUELTO_DIGITAL_BROCHURE_EN_2024.pdf) |
| ランボルギーニ ウラカン Tecnica | 1,379kg | [公式カタログ](https://www.lamborghini.com/sites/it-en/files/DAM/lamborghini/facelift_2019/model_detail/huracan/tecnica/2024/07_22_brochure/Lamborghini%20Hurac%C3%A1n%20Tecnica_ES_WCAG.pdf) |
| ランボルギーニ テメラリオ | 1,690kg | [公式発表](https://www.lamborghini.com/en-en/news/lamborghini-temerario-authentic-fuoriclasse) |
| フェラーリ 12チリンドリ | 1,560kg | [公式発表](https://www.ferrari.com/content/dam/ferrari-fcom/old/pdf/CS_Ferrari_12Cilindri_gbr.pdf) |
| フェラーリ 488 Pista | 1,280kg | [公式諸元](https://www.ferrari.com/content/dam/ferrari-fcom/old/pdf/cs_ferrari_488_pista_geneva_gbr.pdf) |

488 Pistaは同じ公式資料内に乾燥重量1,280kgとkerb weight 1,385kgの両方があり、**105kgの差**がある。ただしkerb weightも日本の登録重量と同一だと決めつけず、仕向地・装備・測定条件を確定する。

これら6件は、単に一律100kgを加算するような訂正はできない。確認できる車両重量が得られるまで、重量条件を「確認済み」として合格判定に使わない仕組みが必要。

## 世代・グレード・装備条件

- **フォレスター4件**: 「6代目（2024-）」にTouring、X-BREAK、Advance、S Limitedと重量1,600〜1,630kgが混在。日本の6代目は2025年4月発売で、SPORT、X-BREAK S:HEV、Premium S:HEVなど。対象行の仕様を再構成する必要がある。[スバル発売資料](https://www.subaru.co.jp/news/2025_04_17_164724/)
- **スペーシア1件**: 3代目カスタムの「HYBRID GS ターボ」はグレードの組み合わせが不整合。GSとXSターボを取り違えていないか特定する。[スズキ発売資料](https://www.suzuki.co.jp/release/a/2023/1109/)
- **CR-V 2件**: 寸法・重量は2026年国内e:HEVの資料と一致するが、2024年開始の世代表示。2024年のe:FCEVと区別して選べるようにする。[ホンダ2026年発売資料](https://global.honda/jp/news/2026/4260226-cr-v.html)
- **X3 G45 PHEV 1件**: 日本向けの参照カタログに該当するxDrive30eの記載がない。海外仕様の可能性があり、日本仕様としての対象特定待ち。不存在とは断定しない。
- **プリウス Z HEV**: 登録の高さ1,430mmと重量1,400kgが、標準19インチと17インチ仕様の組み合わせになっている。装備条件を揃える必要がある。
- **NX450h+**: 1,990kgは18インチ選択時。標準20インチは2,010kg。数値を一律修正するのではなく条件を表示する。
- **インプレッサ ST・ジムニー**: 参照資料にアンテナ格納時の全高という条件がある。インプレッサは発売時資料と後年の標準諸元の高さ・重量が異なるので、全期間共通の「現行型」にまとめない。

**クロストレックの1,575mmは数値誤りから除外した。** 詳細諸元ではシャークフィンアンテナを含む1,575mm、ルーフレール装着時+5mm、当時のTouringオーディオレスはアンテナを倒して-25mmと明記されている。発売発表の1,580mmだけを根拠に訂正すると、誤った修正になる。[2024年12月詳細諸元・注1/2](https://scdam.subaru.jp/20241108/20241108171116crosstrek_specifications.pdf)

## 正しい数値まで書き換えないための注意

- CX-5の4,545×1,840×1,690mmは2018年仕様として成立する。後年の4,575×1,845mmとの差は、まず改良時期の区分の問題として扱う。[マツダ2018年資料](https://newsroom.mazda.com/ja/publicity/release/2018/201802/180208aa.pdf)
- CX-80 XD S Packageの全高1,705mmは正しい。上位グレードの1,710mmを全車へ適用しない。[2025年3月諸元表](https://www.mazda.co.jp/globalassets/assets/cars/cx-80/common/pdf/cx-80_specification_202410.pdf)
- ジムニーシエラは2018年JCの4ATが1,090kg、5MTが1,070kgで区別されており、この2件は4項目とも一致した。[スズキ諸元表](https://www.suzuki.co.jp/suzuki_digital_library/pdf/1_auto/jimnysmall/195.pdf)
- ステップワゴン6代目の登録6件、WR-Vの登録2件、オデッセイの登録2件は、参照した標準仕様の4項目が一致した。出典・対象条件はchecks.csvに記録している。
- 全長・全幅・全高が一致しても、重量・年式・装備条件が未確認なら「全項目確認済み」にしない。

## 修正する順序

1. **判定が変わる高さ・重量の不一致を訂正。** ヴォクシー、セレナ、フリード等を優先。例えば全高制限1,900mmに対し、ヴォクシー4WDは登録1,895mmだと「ギリギリ」、正しい1,925mmだと「NG」になる。これは既存判定式に数値を当てはめた例で、特定施設の再判定結果ではない。
2. **乾燥重量を入庫判定から外す。** 国内の適切な車両重量が確認できるまで重量を未確認として扱う。既存ロジックの欠損時「要確認」を使えるか検討し、種別不明をOKにしない。
3. **世代・グレード・装備の対応を修正。** フォレスターなどの混在を解消。定員、タイヤ、アンテナ、ルーフレールの条件を保存・表示する。
4. **関連記事を同時に更新。** DBの訂正だけではMDX記事の表は直らない。本文の入庫可否の断定も見直す。
5. **出典と確認状態を管理して残りを照合。** 国内の主要諸元表を優先し、年式とグレードを一致させる。輸入車は日本仕様と海外公表値、車体幅とミラー込み幅を特に区別する。

適用時はGit管理の対象限定更新を作り、旧値・車種・世代・グレード・駆動・変速機をすべて検証する。dry-runで対象件数を確認してから反映し、再実行で差分0件・API/画面/関連記事の一致を確認する。
